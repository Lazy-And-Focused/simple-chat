# Super Simpl-Dipl-Papitsquish

This is a simple chat to help you understand and improve your other programming skills

## Stack

- The backend portion of this application is written in Python, and the framework used is FastAPI
- The frontend is written in TypeScript and uses Vue and Nuxt
