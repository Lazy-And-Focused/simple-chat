# SimpleChat

Русский | [English](./docs/en/README.md)

SimpleChat — пет-проект от команды [Lazy And Focused](https://laf-team.ru/), созданный для оттачивания технических и «мягких» навыков.

Ключевые возможности:

- **Группы _(каналы общения)_** для разделения тем
- **Два типа пользователей:** анонимные и зарегистрированные
- **Простой и понятный** интерфейс

## Цель проекта

Главная цель — интенсивное развитие хард-скиллов команды через освоение нового для нас технологического стека. Итогом станет полностью рабочее приложение, готовое к использованию, созданное за один сезонный цикл.

## Технологический стек

- [Python](https://www.python.org/) _(Backend)_
  - [FastAPI](https://fastapi.tiangolo.com/)
- [Node.js](https://nodejs.org/) _(Frontend)_
  - [TypeScript](https://www.typescriptlang.org/)
  - [Nuxt](https://nuxt.com/) & [Vue](https://vuejs.org/)
