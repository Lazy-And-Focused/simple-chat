# SimpleChat

[Russian](../../README.md) | English

SimpleChat is a pet project by the [Lazy And Focused](https://laf-team.ru/) team, created to hone technical and soft skills.

Key features:

- **Groups (communication channels)** for topic separation
- **Two user types:** anonymous and registered
- **Simple and intuitive** interface

## Project Goal

The main goal is the intensive development of the team's hard skills by mastering a technology stack that is new to us. The outcome will be a fully functional application, ready for use, built within one seasonal cycle.

## Technology Stack

- [Python](https://www.python.org/) (Backend)
  - [FastAPI](https://fastapi.tiangolo.com/)
- [Node.js](https://nodejs.org/) (Frontend)
  - [TypeScript](https://www.typescriptlang.org/)
  - [Nuxt](https://nuxt.com/) & [Vue](https://vuejs.org/)
